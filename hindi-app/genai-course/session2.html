Generation Parameters & Tools

The eight knobs that shape every LLM response: temperature, Top-K, Top-P, max tokens, presence and frequency penalties, stop sequences and the system prompt.

Overview

Eight knobs, one mental model

Every API and most playgrounds expose the same controls. Each one answers a different question about how the next token is chosen or when generation stops.

1 · Temperature

Creativity vs determinism

Temperature controls randomness in token selection. Higher gives more diverse, creative output; lower gives predictable, stable output. Engineering intuition: temperature is how bold the model is when picking the next token.

TemperatureOutput behaviour
0.0 to 0.2Deterministic, factual, repeatable
0.5 to 0.7Balanced, natural language
1.0+Creative, risky, divergent
Class demoPrompt: Explain cloud computing in 2 lines.
At temperature 0.1 you get a textbook definition. At 1.5 you get metaphors and storytelling, and occasionally nonsense.
Use lowExams, coding, documentation, anything you must reproduce.
Use highIdeation, brainstorming, naming, creative writing.
2 · Top-K

Vocabulary control

Top-K limits the choice to the K most probable next tokens. Smaller K means a safer, narrower vocabulary; larger K means richer, less predictable text. It says: "only choose from the top K likely next words."

Top-KEffect
1Greedy: the same output every time
10Controlled diversity
50Creative, exploratory
Class demoPrompt: Write a tagline for a cybersecurity product. Compare Top-K 5 against Top-K 40.
Key conceptTop-K is a hard cut-off: a discrete filter that ignores how probability is actually distributed.
3 · Top-P (nucleus sampling)

Probability-mass control

Top-P considers the smallest set of tokens whose cumulative probability reaches P. It adapts: when the model is confident the set is tiny; when it is unsure the set widens. This makes it the dynamic alternative to Top-K.

Top-PBehaviour
0.2Highly precise
0.9Natural language
1.0No restriction
Class demoPrompt: Explain AI to a 10-year-old. Compare Top-P 0.3 against 0.95.
Industry best practiceTune Top-P or Top-K, not both aggressively. Most teams leave Top-K at its default and adjust temperature plus Top-P.
4 · Max tokens

Response-length control

The maximum number of tokens in the output. It prevents runaway responses and caps cost per call.

Class demoAsk for Write an essay on the cow with max tokens = 50, then 300. The 50-token version stops mid-sentence: that is truncation, the main risk of setting this too low. Always check the finish reason in the API response.
5 and 6 · Penalties

Presence penalty and frequency penalty

Presence penalty · idea diversityPenalises returning to a topic already mentioned and nudges the model to introduce new concepts. Intuition: "Have we talked about this already? Then avoid it."

Demo: Generate 5 use cases of Generative AI. At 0.0 the ideas overlap; at 1.0 they are distinct. Great for brainstorming and ideation rounds.
Frequency penalty · word repetitionPenalises reusing the same words in proportion to how often they appeared. Improves lexical variety and avoids loops.

Demo: Write a motivational paragraph at frequency penalty 0 versus 1.2. Useful for essays, marketing copy and blog generators.
7 · Stop sequences

Hard output control

A list of strings that tell the model to stop generating the moment one appears.

"stop": ["###", "END"]

Demo: "Generate steps until ###". Essential in chatbots, multi-turn prompts, agent pipelines and tool-calling workflows where the model must hand control back at a precise point.

8 · System prompt

Behaviour control

The system prompt sets identity, tone and constraints. It carries more weight than a user message and is the foundation of prompt engineering and agent design.

System: You are a strict interviewer. Answer in one sentence only.
User:   How do I make a masala dosa?

Try the same question with and without the system line: the difference in length, tone and format is the whole lesson.

Capabilities and tools worth knowingModern models work across text, code and images. Tools used in the live sessions: NotebookLM (grounded Q&A over your files), Napkin (text to diagrams), Notion AI, Claude, ChatGPT, HeyGen (avatar video) and ElevenLabs (voice).
